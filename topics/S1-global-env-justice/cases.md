## 案例 1：汞的跨國旅程——水俣、Grassy Narrows 與水俣公約
- **對照**：日本水俣病（T118）／加拿大 Grassy Narrows 原住民族（T226）／馬來西亞 Bukit Merah（T096）／水俣公約（T265）
- **故事線**：Chisso 工廠排放甲基汞，1956 年確認水俣病，政府直到 1968 年才承認因果關係。水俣病醫師原田正純 1975 年起前往加拿大安大略省 Grassy Narrows，診斷當地原住民族的汞中毒，使水俣經驗成為跨國知識。2013 年以「水俣」命名的國際汞公約通過，但患者團體批評以地名命名公約，暗示問題已經解決。
- **討論問題**：(1) 為什麼從確認病因到政府承認花了 12 年？誰掌握科學證據的詮釋權？(2) 同一種污染，在日本漁村與加拿大原住民族保留區，受害者面對的國家與法律有什麼不同？(3) 公約以受害地命名，是紀念還是抹除？
- **來源**：https://en.wikipedia.org/wiki/Minamata_disease ; https://en.wikipedia.org/wiki/Grassy_Narrows_First_Nation ; https://en.wikipedia.org/wiki/Minamata_Convention_on_Mercury ；讀物 S1-067、S1-068、S1-071

## 案例 2：Bhopal 與雙重標準——跨國企業的責任邊界
- **對照**：印度 Bhopal（T079）／義大利 Seveso（T181）／印度 Oleum 案與絕對責任（T080）
- **故事線**：1984 年 Union Carbide 印度子公司異氰酸甲酯外洩，數千人立即死亡。1989 年和解金僅 4.7 億美元。同一時期，歐洲在 1976 年 Seveso 事故後於 1982 年通過嚴格的工業風險指令。印度最高法院則在 1987 年 Oleum 案中確立危險產業的「絕對責任」。
- **討論問題**：(1) 同一家企業在美國本土與印度的安全標準是否相同？(2) 為什麼和解金額如此之低？(3) 南方國家的法院如何發展出比北方更嚴格的責任原則？
- **來源**：https://en.wikipedia.org/wiki/Bhopal_disaster ; https://en.wikipedia.org/wiki/Seveso_disaster ; https://en.wikipedia.org/wiki/M._C._Mehta_v._Union_of_India ；讀物 S1-061

## 案例 3：石油、少數族群與跨國訴訟——Ogoni 與厄瓜多亞馬遜
- **對照**：奈及利亞 Ogoni（T043–T045、T052、T059）／厄瓜多 Lago Agrio（T009）／Oilwatch（T011）
- **故事線**：Shell 在 Ogoniland、Texaco 在厄瓜多亞馬遜開採石油數十年，留下嚴重污染。兩地受害者都到北方國家的法院（紐約、海牙）提起訴訟，並在 1996 年透過 Oilwatch 串連。Ken Saro-Wiwa 1995 年被處決，厄瓜多原告則在 2011 年贏得判決，卻因 Chevron 的國際仲裁與反訴難以執行。
- **討論問題**：(1) 為什麼受害者要到北方國家起訴？(2) 「把石油留在地下」的主張從何而來？(3) 比較兩案中國家（軍政府 vs. 民選政府）的角色。
- **來源**：https://en.wikipedia.org/wiki/Movement_for_the_Survival_of_the_Ogoni_People ; https://en.wikipedia.org/wiki/Aguinda_v._Texaco,_Inc. ; https://www.oilwatch.org/ ；讀物 S1-044、S1-045、S1-047

## 案例 4：誰的垃圾？——Koko、海地與巴塞爾公約
- **對照**：奈及利亞 Koko（T040）／海地 Khian Sea（T008）／象牙海岸 Probo Koala（T050）／迦納 Agbogbloshie（T057）／台塑柬埔寨汞污泥（T104）
- **故事線**：1980 年代末北方國家廢棄物處理成本上升，有毒廢棄物大量輸往非洲與加勒比海。1991 年世界銀行 Summers 備忘錄（T248）主張這在經濟上合理。非洲國家推動 1989 年巴塞爾公約，但不滿其未全面禁止，另立 1991 年巴馬科公約。1998 年台塑將含汞廢棄物運到柬埔寨，顯示亞洲內部也有同樣的結構。
- **討論問題**：(1) Summers 備忘錄的「經濟邏輯」錯在哪裡？(2) 為什麼巴塞爾公約花了 30 年才讓「禁運修正案」生效？(3) 台灣在廢棄物貿易中的位置是什麼？
- **來源**：https://en.wikipedia.org/wiki/Basel_Convention ; https://en.wikipedia.org/wiki/Bamako_Convention ; https://en.wikipedia.org/wiki/Summers_memo ；讀物 S1-010；台塑柬埔寨案（待查證：1998–99 年新聞與 BAN 資料）

## 案例 5：森林裡的人——Chico Mendes、Chipko 與 Penan
- **對照**：巴西 Acre 橡膠工人（T002–T007）／印度 Chipko（T076）／砂拉越 Penan（T098）／台灣司馬庫斯櫸木案（T164）
- **故事線**：1970–80 年代，巴西、印度與馬來西亞的森林居民分別以人牆、抱樹與封路阻擋伐木。他們的訴求不是「保護無人的荒野」，而是「保護我們賴以為生的森林」。Chico Mendes 的「採集保護區」把人與森林放在一起保護。台灣司馬庫斯部落族人撿拾風倒櫸木遭起訴，最後在 2010 年獲判無罪，法院承認原住民族傳統慣習。
- **討論問題**：(1) 「窮人的環境主義」和美國的荒野保育有什麼不同？（可搭配 Guha 1989，S1-003）(2) 國家公園與保護區對在地居民是保護還是排除？
- **來源**：https://en.wikipedia.org/wiki/Chico_Mendes ; https://en.wikipedia.org/wiki/Chipko_movement ; https://en.wikipedia.org/wiki/Penan_people ; https://zh.wikipedia.org/wiki/司馬庫斯風倒櫸木案 ；讀物 S1-001、S1-004、S1-031

## 案例 6：核廢料與原住民族土地——蘭嶼、Navajo 與太平洋（台灣核心案例）
- **對照**：台灣蘭嶼（T154、T175）／美國 Navajo 鈾礦（T224、T229）／澳洲 Jabiluka（T209）／韓國扶安（T131）／馬紹爾群島（T201、T202）
- **故事線**：1982 年台電在蘭嶼設置核廢料貯存場，2018 年行政院真相調查報告認定達悟族人對設置決策「應不知情」。1988 年 2 月 20 日，達悟族青年發起第一次「驅逐惡靈」行動。2016 年總統道歉，2019 年政府公布一次性 25.5 億元回溯補償、另每三年 2.2 億元，但族人強調補償不能取代遷出，核廢料至今仍在島上。類似模式出現在美國 Navajo 保留區的鈾礦、澳洲 Mirarr 族土地、太平洋核試場。
- **討論問題**：(1) 為什麼核子產業鏈的「最前端」（鈾礦）與「最末端」（核廢料、核試）常常在原住民族土地上？(2) 「核殖民主義」這個概念是否適用於台灣？(3) 「諮商同意權」能否解決選址的不正義？
- **來源**：https://ec.ltn.com.tw/article/paper/1333933 ; https://tfc-taiwan.org.tw/?p=109384 ; https://en.wikipedia.org/wiki/Lanyu_nuclear_waste_storage_facility ; https://en.wikipedia.org/wiki/Uranium_mining_and_the_Navajo_people ; https://en.wikipedia.org/wiki/Jabiluka_uranium_mine ；讀物 S1-080、S1-081、S1-085、S1-091

## 案例 7：高科技的隱藏成本——RCA 與三星（台灣核心案例）
- **對照**：台灣 RCA 桃園廠（T158）／韓國三星白血病（T133）／台灣日月光 K7（T168）
- **故事線**：美商 RCA 在桃園設廠生產電子產品，長期傾倒有機溶劑污染地下水。1994 年污染曝光後，前員工發現罹癌率異常，1998 年成立員工關懷協會，2004 年提起集體訴訟。2015 年一審判賠 5.64 億元；2018 年最高法院判決 262 人約 5 億元定讞，另 246 人發回更審。韓國三星半導體工人罹患白血病，家屬組成 Banolim，2018 年與三星達成協議。兩地團體互相聲援。
- **討論問題**：(1) 職業病的因果證明為什麼困難？流行病學在法庭上扮演什麼角色？(2) 跨國企業撤資、改組後，責任如何追究？(3) 台灣半導體業今天面對什麼樣的環境與職業健康議題？
- **來源**：https://news.pts.org.tw/article/403242 ; https://zh.wikipedia.org/wiki/RCA污染事件 ; https://en.wikipedia.org/wiki/Samsung_Electronics ；讀物 S1-084（待查證）

## 案例 8：台塑的跨國足跡——麥寮、河靜、施亞努港與路易斯安那（台灣核心案例）
- **對照**：雲林六輕（T159）／柬埔寨汞污泥（T104）／越南河靜鋼廠（T114）／美國 Sunshine Project（T238）
- **故事線**：台塑集團在台灣、柬埔寨、越南與美國都引發環境爭議。2016 年河靜鋼廠排放導致越南中部大量魚類死亡，台塑承認並賠償 5 億美元；越南抗議者則遭判刑。美國路易斯安那州「癌症巷」的黑人社區反對台塑新建石化廠，2022 年州地方法院撤銷其空污許可，但 2024 年 1 月上訴法院推翻原判、恢復許可。台灣、越南與美國的公民團體形成跨國聯盟。
- **討論問題**：(1) 台灣企業的跨國環境責任應由誰監督？(2) 這個案例如何挑戰「南方是受害者、北方是加害者」的二分？(3) 跨國公民聯盟能做什麼、不能做什麼？
- **來源**：https://en.wikipedia.org/wiki/2016_Vietnam_marine_life_disaster ; https://en.wikipedia.org/wiki/Cancer_Alley ; https://lailluminator.com/2024/01/26/appeals-court-rules-in-favor-of-formosa-plastics-facility-in-st-james/ ; https://en.wikipedia.org/wiki/Mailiao_Refinery ; https://en.wikipedia.org/wiki/Formosa_Plastics_Group

## 案例 9：鹿港反杜邦——戒嚴下的環境運動與民主化
- **對照**：台灣鹿港（T149）／韓國溫山病（T127）／匈牙利多瑙圈（T182）／保加利亞 Ecoglasnost（T185）
- **故事線**：1986 年美商杜邦計畫在鹿港設二氧化鈦廠，居民在戒嚴下上街，1987 年杜邦撤資。同一時期，韓國、匈牙利、保加利亞的環境運動也成為對抗威權的突破口。
- **討論問題**：(1) 為什麼環境議題常成為威權體制下最早的抗爭議題？(2) 鹿港的訴求是「環境」還是「地方利益」？這兩者能分開嗎？
- **來源**：https://zh.wikipedia.org/wiki/鹿港反杜邦運動 ; https://en.wikipedia.org/wiki/Gab%C4%8D%C3%ADkovo%E2%80%93Nagymaros_Dams ; https://en.wikipedia.org/wiki/Ecoglasnost ；讀物 S1-075、S1-079

## 案例 10：河流有權利嗎？——厄瓜多、紐西蘭、哥倫比亞
- **對照**：厄瓜多憲法（T019）／紐西蘭 Whanganui 河與 Te Urewera（T210）／哥倫比亞 Atrato 河（T031）／玻利維亞地球母親法（T022）
- **故事線**：2008 年厄瓜多首度將自然權利寫入憲法；2014 與 2017 年紐西蘭以毛利世界觀賦予森林與河流法律人格；2016 年哥倫比亞憲法法院承認 Atrato 河為權利主體。三者的思想來源不同：安地斯 Pachamama、毛利祖先觀、生物文化權利。但玻利維亞在通過地球母親法的同時，也擴大採掘（TIPNIS，T023）。
- **討論問題**：(1) 法律人格能保護河流嗎？誰代表河流發言？(2) 這是西方法律吸收原住民族世界觀，還是原住民族法律被西方框架馴化？(3) 台灣的河川或山林能否適用？
- **來源**：https://en.wikipedia.org/wiki/Rights_of_nature ; https://en.wikipedia.org/wiki/Whanganui_River ; https://en.wikipedia.org/wiki/Atrato_River ；讀物 S1-033、S1-034、S1-041

## 案例 11：從「沉沒的島」到國際法院——太平洋氣候正義
- **對照**：馬紹爾群島核試（T201）／太平洋氣候戰士（T211）／Teitiota 案（T212）／Torres 海峽島民案（T214）／太平洋學生與 ICJ（T215）／損失與損害（T262、T074）
- **故事線**：太平洋島民曾是核試的受害者，如今是氣候變遷的前線。他們拒絕「沉沒受害者」的形象，喊出「我們不是在沉沒，我們在戰鬥」。2019 年南太平洋大學的法律系學生發起運動，促成聯合國大會請求國際法院發表氣候諮詢意見，2025 年國際法院確認各國負有氣候義務。
- **討論問題**：(1) 小國如何利用國際法改變大國行為？(2) 核試與氣候變遷有什麼共同的結構？(3) 氣候遷移者應該被稱為「難民」嗎？
- **來源**：https://en.wikipedia.org/wiki/Pacific_Islands_Students_Fighting_Climate_Change ; https://www.icj-cij.org/case/187 ; https://en.wikipedia.org/wiki/Nuclear_testing_at_Bikini_Atoll ；讀物 S1-090、S1-092

## 案例 12：綠色轉型的代價——鋰、鈷、風場
- **對照**：南美鋰三角（T034）／剛果鈷（T054）／美國 Thacker Pass（T241）／塞爾維亞 Jadar（T197）／挪威 Fosen 風場（T223）／台灣大潭藻礁（T172）
- **故事線**：減碳需要電池與再生能源，但鋰、鈷、稀土的開採和風場的興建正在原住民族與農民土地上製造新的衝突。挪威最高法院 2021 年判決 Fosen 風場侵害薩米人文化權；剛果手工鈷礦使用童工。台灣的藻礁公投顯示，能源轉型與生態保育在台灣也有張力。
- **討論問題**：(1) 「綠色殖民主義」是否是公平的批評？(2) 能源轉型的「公正」應包括誰？(3) 你的手機與電動車電池來自哪裡？（可搭配 activities.md 的供應鏈追蹤活動）
- **來源**：https://en.wikipedia.org/wiki/Fosen_Vind ; https://www.amnesty.org/en/documents/afr62/3183/2016/en/ ; https://en.wikipedia.org/wiki/Thacker_Pass_lithium_mine ; https://en.wikipedia.org/wiki/2021_Taiwanese_referendum
