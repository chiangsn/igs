# 記憶（Memory）

> `T###` 指向 `../data/timeline.csv`（S2-T###）。理論脈絡見 `../historiography.md` 第七節。

## 歷史演變

1. **國家紀念與「無名戰士」（一戰後）**：一戰後各國建立紀念碑與「無名戰士墓」，但殖民地士兵很少被具名紀念；英聯邦戰爭墓地委員會 2021 年承認對非洲與亞洲死者的不平等紀念（T065）。加里波利則成為澳紐國族記憶的起點（T120）。
2. **受害與加害的記憶（二戰後）**：德國發展出「克服過去」的記憶文化，絆腳石計畫以地面上的小銅牌紀念個別受害者（T099）；日本的戰爭記憶以廣島的「受害」為中心，靖國神社合祀甲級戰犯引發中韓抗議（T016、T007）。
3. **冷戰的沉默與解禁**：濟州四三（T011）、光州（T017）、印尼 1965（T030）、西班牙內戰（T091、T107）在冷戰期間都是禁忌，民主化後才開始調查與紀念。
4. **殖民戰爭的記憶（2000 年代以後）**：法國的斯托哈報告（T062）、德國與納米比亞的聯合聲明（T063）、英國與茅茅受害者和解（T083）、紐西蘭設立戰爭紀念日（T129）、澳洲殖民邊疆屠殺地圖（T131）。
5. **戰爭記憶與當代政治**：愛沙尼亞 2007 年的網路攻擊起因於蘇軍紀念碑遷移（T106）；巴米揚大佛被毀把文化遺產帶進戰爭記憶議題（T045）。

## 東亞的戰爭記憶

東亞是戰爭記憶爭議最激烈的區域：南京的數字（T004）、慰安婦（T002、T022）、靖國神社（T016）、日本國憲法第九條（T010）、沖繩（T015）。台灣的戰爭記憶則是多重記憶並存：台籍日本兵與高砂義勇隊（T005）、1949 年來台的軍民與眷村（T012）、金門的戰地記憶（T014）。這些記憶在台灣常彼此競爭，也可以用 Rothberg 的「多向記憶」來分析（見 `../data/concepts.csv`）。
