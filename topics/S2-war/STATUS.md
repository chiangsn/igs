# S2 STATUS：戰爭與其延伸影響

最後更新：2026-11-27（第四輪：跨國連結完成）

## 研究計畫與分析架構

兩條軸線：**戰爭的類型**（7 類）×**延伸影響的面向**（13 個），再放進六個歷史分期。完整說明見 `overview.md` 第二節。

- **戰爭類型**（timeline `issue` 關鍵字）：interstate war、civil war、colonial war、proxy war、genocide／mass atrocity、terrorism、hybrid war。
- **影響面向**（`impacts/` 各一份）：refugees、humanitarian law、environment、health、economy／food、gender、children、landmines、arms trade、nuclear、memory、transitional justice、peacekeeping；另有貫穿性關鍵字 colonialism、world order、civilians。
- **歷史分期**（為符合 `CLAUDE.md` 的「YYYY–YY 年」寫法，第四、五期邊界定在 1999／2000）：
  1. 殖民征服與帝國戰爭（1914 年以前）
  2. 世界大戰與總體戰（1914–1945）
  3. 去殖民、冷戰與熱戰（1946–1989）
  4. 冷戰後的「新戰爭」與人道干預（1990–1999）
  5. 反恐戰爭與國際刑事司法（2000–2010）
  6. 大國競爭回歸與多重危機（2011 年至今）

**工作方式**：每輪以數個研究 agent 分區域蒐集事件與讀物（每輪共用 200 次網路搜尋額度）；S2 負責概念表、所有敘事文件、合併、查證與一致性檢查。

## 3. 結論

1. 「延伸影響」框架在資料上站得住：249 筆事件中，最常出現的關鍵字是 civilians（112）、memory（89）、world order（88）、transitional justice（64）、humanitarian law（59）、refugees（57），多於戰爭類型關鍵字（civil war 50、interstate war 46）。
2. 戰後的轉型正義實踐集中在拉美、非洲與東亞：拉美 27 筆中約一半是真相委員會、審判與運動。
3. 東亞與台灣的中文材料最豐富；非洲、拉美、中東的中文材料非常少，這本身是值得教學討論的發現。
4. 當代衝突（烏克蘭、加薩、蘇丹、緬甸）都以「事實＋認定者＋各方主張」的方式呈現，不下政治判斷。
