# 後續任務：S2 — 標記跨國連結（`data/links.csv`）

> 建立：2026-11-27（S0 撰寫）
> 開場：使用者在既有的 S2 session 貼上「下一個任務：請讀 `prompts/S2-links.md`」。

## 1. 這個任務是什麼

使用者覺得網站上的網絡圖很難詮釋，原因是 `linked_ids` 只記錄「有關」，沒有記錄是哪一種關係、方向從哪裡到哪裡。所以改用 `data/links.csv` 專門記錄跨國連結，每條連結標出兩件事：

- 流動的是什麼（`flow`）；
- 怎麼連起來的（`mechanism`）。

S1 已經試標並全面標記，分類依 S1 的經驗修訂成第二版。現在輪到 S2、S3、S4，三個主題平行進行。網站會自動讀取 `links.csv`，產生跨國流向地圖、區域泳道弧線圖和斷裂圖。

**S2 的情況**：S0 用 `linked_ids` 統計：

| 項目 | 數量 |
|---|---|
| 連結對 | 177 對 |
| 跨國或連到 Global 的候選 | 147 對 |
| 其中跨區域的（不含 Global） | 只有 9 對 |
| 連到其他主題的 | 31 對 |
| 多國事件 | 122 筆 |

所以 S2 的重點**不是替現有的 `linked_ids` 分類，而是補上原本沒記錄的跨國連結**。戰爭的延伸影響本來就是跨國的：

- 難民跨越國界；
- 軍火和地雷從生產國流到戰場；
- 戰爭罪由國際法庭審理；
- 一地的轉型正義模式被另一地借用。

這正是 S2 論點的核心，S2 的「戰爭類型 × 延伸影響面向」矩陣可以當成找連結的地圖。

## 3. 範圍

**要做：**

1. **整理 `country`**：
   - 多國事件照新規定，改成受影響地在前、外部的主要行動者在後。例如越戰寫 `Vietnam; United States`。
   - S2 有 122 筆多國事件，先整理這一步，同國判斷和網站推導都依賴它。
   - 兩方對等、分不出誰是外部行動者的，例如兩國交戰，依 `actors` 的順序，並在 `STATUS.md` 說明。
   - 只改 `country`，不改 id。
2. **從現有的 `linked_ids` 標記**：147 對候選中，有實質關聯的才標，比較案例不收。
3. **補上缺少的跨國連結**，優先找以下幾類：
   - **難民與流離**：`people`，例如戰爭 → 收容國的難民潮 → 難民公約或國際制度；
   - **軍火、地雷、未爆彈、化學武器**：`material`、`technology`，例如生產國與戰場、橙劑；
   - **國際刑事司法**：`litigation`、`scale_up`，例如前南、盧安達法庭 → 國際刑事法院；
   - **轉型正義與和解模式的傳播**：`template`、`diffusion`，例如南非真相與和解委員會被其他國家借用；
   - **記憶的相互引用**：`memory`，例如大屠殺記憶與其他種族滅絕的認定；
   - **殖民戰爭的延續**：`colonial`，例如德國與納米比亞、英國與肯亞的道歉與賠償；
   - **代理戰爭與冷戰介入**：`geopolitical`；
   - **反制和規避**：`contestation`、`evasion`，例如不簽署禁雷公約、繞過武器禁運。
4. **跨主題**：可以連到 S1、S3、S4 的事件，例如戰爭的環境影響連 S1，軍事技術連 S3，戰後重建與發展援助連 S4。
5. **每條都要有來源**：要能支持「這兩件事有關聯」，不能只引用兩個事件各自的來源。找不到的不收；部分支持的，在 `sources` 註明哪一部分待查證。
6. **寫 `data/links-caveats.md`**：照 `link-typology.md` 第 8 節，格式照 S1。要寫出 S2 特有的偏誤，例如：
   - 多國事件多，有些跨國關係其實在事件內部，沒有另一端可以連；
   - 國際制度的文件會自述起源，所以 `scale_up` 容易找到來源。
7. **檢查腳本**：寫一支 `data/scripts/validate_links.py`，可以參考 S1 的同名腳本，但要改成第二版的欄位和 14 類機制。檢查：
   - 所有 id 都存在；
   - 詞彙都在清單內；
   - `mechanism_2` 不能和 `mechanism` 相同；
   - 沒有同國的連結；
   - 沒有重複；
   - 每條都有來源和說明。

**不做：**
- 不新增事件，除非某條關鍵連結的另一端在任何主題都沒有。新增的事件接在檔尾，一樣要有來源。
- 不修改其他主題的檔案，也不修改共用檔。
- 不修改 `link-typology.md`。對分類的建議寫在 `STATUS.md` 給 S0。
