# 後續任務：S3 — 標記跨國連結（`data/links.csv`）

> 建立：2026-11-27（S0 撰寫）
> 開場：使用者在既有的 S3 session 貼上「下一個任務：請讀 `prompts/S3-links.md`」。

## 1. 這個任務是什麼

使用者覺得網站上的網絡圖很難詮釋，原因是 `linked_ids` 只記錄「有關」，沒有記錄是哪一種關係、方向從哪裡到哪裡。所以改用 `data/links.csv` 專門記錄跨國連結，每條連結標出兩件事：

- 流動的是什麼（`flow`）；
- 怎麼連起來的（`mechanism`）。

S1 已經試標並全面標記，分類依 S1 的經驗修訂成第二版。現在輪到 S2、S3、S4，三個主題平行進行。網站會自動讀取 `links.csv`，產生跨國流向地圖、區域泳道弧線圖和斷裂圖。

**S3 的情況**：S0 用 `linked_ids` 統計：

| 項目 | 數量 |
|---|---|
| 連結對 | 283 對 |
| 跨國或連到 Global 的候選 | 250 對 |
| 其中跨區域的（不含 Global） | 95 對 |
| 連到其他主題的 | 20 對 |
| 多國事件 | 94 筆 |

S3 的候選很多，跨區域的比例也高。技術移轉本身就是跨國連結，這個任務可以直接檢驗 S3 的論點：技術移轉、適當技術、科技政治三個概念不是依序取代，而是重疊並存。標完之後，網站上應該看得出這三種關係在各時期、各區域的消長。

## 3. 範圍

**要做：**

1. **整理 `country`**：
   - 多國事件照新規定，改成受影響地在前、外部的主要行動者在後。例如蘇聯援建的工程寫 `<受援國>; Soviet Union`。
   - 只改 `country`，不改 id。
2. **從現有的 `linked_ids` 標記**：250 對候選中，有實質關聯的才標，比較案例不收。
3. **三個概念和機制的對應**，供參考，不是硬性規定：
   - **技術移轉**：
     - 援助和技術轉移是 `technology`、`capital`；
     - 以援助為條件要求採用某套技術或制度，標 `imposition`；
     - 冷戰陣營的技術援助，標 `geopolitical`；
     - 照抄的制度，例如各國設立原子能機構，標 `template`；
   - **適當技術**：
     - 運動和組織的跨國學習，標 `diffusion`；
     - 把外來技術改寫成在地版本，標 `translation`；
     - 拒絕現代化路線、另立一套，標 `contestation`；
   - **科技政治**：
     - 供應鏈，例如半導體、稀土，標 `commodity_chain`；
     - 出口管制和科技競爭，標 `geopolitical`；
     - 規避出口管制或標準，標 `evasion`；
     - 帝國科技與殖民科學的延續，標 `colonial`。
   - **物質一定要標**：礦產、晶片、零件、電子廢棄物都是 `material`。
4. **補上缺少的跨國連結**：特別是南南之間的技術合作，以及東亞追趕過程中的技術來源，例如日本 → 台灣、韓國的半導體與機械。
5. **跨主題重複事件**：例如 S3-T229 和 S1-T200 都是諾魯磷礦。不做成連結，在 S3 這一端的 `linked_ids` 引用對方，並在 `data/README.md` 列出「與其他主題重複的事件」。
6. **跨主題連結**：可以連到 S1、S2、S4 的事件，例如：
   - 技術移轉帶來的污染，連 S1；
   - 軍事技術，連 S2；
   - 聯合國的科技與發展會議，連 S4。
7. **每條都要有來源**：要能支持「這兩件事有關聯」，不能只引用兩個事件各自的來源。找不到的不收；部分支持的，在 `sources` 註明哪一部分待查證。
8. **寫 `data/links-caveats.md`**：照 `link-typology.md` 第 8 節，格式照 S1，寫出 S3 特有的偏誤。
9. **檢查腳本**：寫一支 `data/scripts/validate_links.py`，可以參考 S1 的同名腳本，但要改成第二版的欄位和 14 類機制。檢查：
   - 所有 id 都存在；
   - 詞彙都在清單內；
   - `mechanism_2` 不能和 `mechanism` 相同；
   - 沒有同國的連結；
   - 沒有重複；
   - 每條都有來源和說明。

**順便處理**：SZ 在 S3 上網站時回報，`STATUS.md` 和 `data/README.md` 提到已移除的 `S3-146`，網站會誤判成 id。請改寫成不像 id 的形式，例如「原 146 號」。

**不做：**
- 不新增事件，除非某條關鍵連結的另一端在任何主題都沒有。新增的事件接在檔尾，一樣要有來源。
- 不修改其他主題的檔案，也不修改共用檔。
- 不修改 `link-typology.md`。對分類的建議寫在 `STATUS.md` 給 S0。
