# 後續任務：S4 — 標記跨國連結（`data/links.csv`）

> 建立：2026-11-27（S0 撰寫）
> 開場：使用者在既有的 S4 session 貼上「下一個任務：請讀 `prompts/S4-links.md`」。

## 1. 這個任務是什麼

使用者覺得網站上的網絡圖很難詮釋，原因是 `linked_ids` 只記錄「有關」，沒有記錄是哪一種關係、方向從哪裡到哪裡。所以改用 `data/links.csv` 專門記錄跨國連結，每條連結標出兩件事：

- 流動的是什麼（`flow`）；
- 怎麼連起來的（`mechanism`）。

S1 已經試標並全面標記，分類依 S1 的經驗修訂成第二版。現在輪到 S2、S3、S4，三個主題平行進行。網站會自動讀取 `links.csv`，產生跨國流向地圖、區域泳道弧線圖和斷裂圖。

**S4 的情況**：S0 用 `linked_ids` 統計：

| 項目 | 數量 |
|---|---|
| 連結對 | 119 對 |
| 跨國或連到 Global 的候選 | 116 對 |
| 其中連到 Global 的 | 105 對 |
| 跨區域的（不含 Global） | 只有 3 對 |
| 連到其他主題的 | 24 對 |

網站的網絡圖因此變成以聯合國會議為中心的星狀。

**S4 要特別注意兩件事**：

1. **兩端都是 Global 的不收。**例如斯德哥爾摩會議 → 里約會議、MDGs → SDGs 這類全球層次內部的制度沿革，不符合「跨國」的定義，留在 `linked_ids`。S1 也照這個原則排除了 18 對。全球治理的制度沿革本來就是 S4 的主軸，網站上原本的網絡圖和三條線索的論點視圖仍然會呈現。`links.csv` 要呈現的是另一面：**全球規範和各國、各區域之間的來回**。
2. **重點是補上缺少的連結**，不只是替現有的候選分類。S4 的論點裡有很多全球與地方之間的雙向關係，例如：
   - 南方國家的聯盟推動議程，例如 G77、新國際經濟秩序，標 `scale_up`；
   - 各國照抄全球模式，例如設立環境部會、國家永續發展委員會，標 `template`；
   - 結構調整的條件，標 `imposition`；
   - 各國改寫 SDGs，標 `translation`；
   - 反對或另立框架，例如西雅圖反 WTO、另類全球化運動、Buen Vivir，標 `contestation`；
   - 規範已經存在卻沒被遵守，標 `evasion`。

## 3. 範圍

**要做：**

1. **整理 `country`**：
   - 多國事件（15 筆）照新規定，改成受影響地在前、外部的主要行動者在後；
   - 只改 `country`，不改 id。
2. **從現有的 `linked_ids` 標記**：116 對候選中，有實質關聯、而且不是兩端都是 Global 的，才標。比較案例不收。
3. **補上缺少的跨國連結**：照第 1 節列的幾類找，並特別注意：
   - 國家或區域之間的連結，不經過 Global，例如區域組織之間的仿效、南南合作；
   - 一手文件（`documents.csv`）中自述起源或影響的段落，常常可以直接當成來源。
4. **跨主題**：可以連到 S1、S2、S3 的事件，例如：
   - 環境正義運動推動國際公約，連 S1；
   - 戰後重建，連 S2；
   - 技術援助與適當技術，連 S3。
5. **每條都要有來源**：要能支持「這兩件事有關聯」，不能只引用兩個事件各自的來源。找不到的不收；部分支持的，在 `sources` 註明哪一部分待查證。
6. **寫 `data/links-caveats.md`**：照 `link-typology.md` 第 8 節，格式照 S1。要寫出 S4 特有的偏誤，例如：
   - Global 事件佔大多數；
   - 全球層次內部的制度沿革不在 `links.csv` 中；
   - 聯合國文件會自述起源，所以 `scale_up` 和 `template` 容易找到來源。
7. **檢查腳本**：寫一支 `data/scripts/validate_links.py`，可以參考 S1 的同名腳本，但要改成第二版的欄位和 14 類機制。檢查：
   - 所有 id 都存在；
   - 詞彙都在清單內；
   - `mechanism_2` 不能和 `mechanism` 相同；
   - 沒有同國的連結；
   - 沒有兩端都是 Global 的連結；
   - 沒有重複；
   - 每條都有來源和說明。

**不做：**
- 不新增事件，除非某條關鍵連結的另一端在任何主題都沒有。新增的事件接在檔尾，一樣要有來源。
- 不修改其他主題的檔案，也不修改共用檔。
- 不修改 `link-typology.md`。對分類的建議寫在 `STATUS.md` 給 S0。
